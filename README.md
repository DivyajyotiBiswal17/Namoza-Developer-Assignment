### To test Task 2 locally

-Open task2-landing-page.html directly in a browser (double-click works, no server required).

-Open DevTools console.

-Fill in Name + a valid 10-digit Indian mobile number (must start with 6-9), click "Book My Free Consultation".

-Run window.dataLayer in the console — you'll see the consultation_form_submitted push logged, and the page swaps to a thank-you state without reloading.
